# Whisk Email Signature Generator

A beautiful, easy-to-use web application for generating professional email signatures for the Whisk team at Samsung Food.

## Features

✨ **Real-time Preview** - See your signature update as you type

🎨 **Modern Design** - Beautiful, responsive interface with Samsung branding

📱 **Mobile Friendly** - Works on all devices

⬇️ **Easy Download** - Export your signature as a high-quality PNG image

📋 **Copy HTML** - Copy the signature HTML directly to clipboard

🎯 **Smart Highlighting** - Hover over input fields to see which part of the signature they affect

✏️ **Auto-Select Text** - Click any field to automatically select all text for easy editing

📝 **Gmail Instructions** - Step-by-step guide for adding your signature to Gmail

## How to Use

1. Open `index.html` in your web browser
2. Fill in your information:
   - First and Last Name
   - Job Title/Role
   - Phone (optional)
   - Email Address
3. Watch the preview update in real-time
4. Click "Download Signature" to save as an image
5. Follow the instructions to add it to your Gmail account

## Customization

The signature follows Samsung Food branding with:
- Whisk team designation
- Samsung Food logo and tagline
- Professional gradient purple theme
- Clean, modern typography

To customize the colors or styling, edit the CSS variables in the `<style>` section of `index.html`.

## Browser Compatibility

Works in all modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera

## Technical Details

Built with:
- Pure HTML/CSS/JavaScript (no build process required)
- html2canvas library for image generation
- Responsive grid layout
- Modern CSS gradients and animations
